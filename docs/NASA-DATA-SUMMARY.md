# بيانات ناسا والمصادر المفتوحة في OrbitCare — ملخّص سريع

ثلاث فئات، مفصولة بأمانة (مهم لحتى ما نقول "بيانات ناسا" عن إشي مش من ناسا).

---

## 1) بيانات ناسا الحقيقية المستخدمة  ← الوحيدة من ناسا فعلاً

### NASA OSDR RadLab — إشعاع محطة الفضاء الدولية (ISS)
| البند | التفاصيل |
|---|---|
| **شو هي** | معدّل الجرعة الإشعاعية الممتصة (absorbed dose rate) على محطة ISS |
| **الكاشف** | DosTel1، في موديول Columbus |
| **التاريخ** | يوم كامل: 2022-04-01 (UTC) |
| **الوحدة** | µGy/h (ميكروغراي/ساعة) — كما نشرتها ناسا بالظبط |
| **بتعمل شو بالموقع** | بتغذّي **الدوزيميتر الشخصي** على السترة → قراءة الإشعاع الحيّة + متوسط اليوم + متوسط×24 ساعة (المتوسط مُشتَق) |
| **الرابط** | https://visualization.osdr.nasa.gov/radlab/ |
| **الرخصة** | بيانات ناسا المفتوحة (شروط OSDR) |
| **الكود** | `cli/ingest-open-sensors.php` → جدول `sensor_sources` / `sensor_samples` → `GET /api/health/sensors` |

> API المستخدم:
> `https://visualization.osdr.nasa.gov/radlab/api/?spacecraft=ISS&instrument=DosTel1&timestamp>=2022-04-01T00:00&timestamp<2022-04-02T00:00&absorbed_dose_rate&module&format=csv`

قواعد النظافة: أي قراءة ناقصة أو مستحيلة (< 0 أو > 1000 µGy/h) بتترفض، والتواريخ المكررة بتتخزّن مرة وحدة. ما منعبّي أي فراغ.

## 3) بيانات مفتوحة **مش من ناسا**  ← للأمانة: من PhysioNet

هاي بتشغّل المؤشرات الحيوية والمحاكاة، بس **مش بيانات ناسا ولا بيانات رواد فضاء** — مرضى/متطوعين على الأرض. منقولها بصراحة.

### BIDMC (PhysioNet) — المؤشرات الحيوية الحيّة
| البند | التفاصيل |
|---|---|
| **شو** | 53 تسجيل، 8 دقائق، مرضى عناية مركّزة (مش رواد فضاء) |
| **بتعمل** | الموجات الحيّة 125Hz: تخطيط القلب II، نبض PPG، التنفّس RESP → تظهر على سينسورز السترة وعصابة الرأس |
| **الرابط** | https://physionet.org/content/bidmc/1.0.0/ |

### noneeg (PhysioNet) — سينسورز الجسم الباقية
| البند | التفاصيل |
|---|---|
| **شو** | 20 متطوع سليم، سينسورز معصم 8Hz |
| **بتعمل** | حرارة الجلد (°م)، التوصيل الجلدي GSR، الحركة (مُشتقّة) → على السترة |
| **الرخصة** | ODC-By 1.0 |
| **الرابط** | https://physionet.org/content/noneeg/1.0.0/ |

> متطوعو noneeg أشخاص مختلفون عن مرضى BIDMC، وكل قراءة بتقول من وين إجت. العصابة ما إلها EEG حقيقي، فموجات النوم تبقى **مُحاكاة (SIMULATED DATA)**.

## خلاصة بسطر
- **من ناسا فعلاً:** الإشعاع فقط (OSDR RadLab) — بيانات حقيقية من ISS.
- **مراجع ناسا:** صفحات المخاطر الخمسة (علم، مش داتا).
- **مش ناسا:** المؤشرات الحيوية والحرارة/GSR من PhysioNet (أشخاص على الأرض، موضّح بصراحة).
